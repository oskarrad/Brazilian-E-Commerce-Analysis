# ETL Project - Brazilian E-Commerce-Analysis

## Project Overview 
The goal of this project is to analyze e-commerce data.  
The objective is to identify key sales patterns, delivery performance, and customer behavior.

## Tools Used
The analysis was performed using multiple tools:

- **Python (pandas)** and **Excel (Power Query)** for ETL processes  
- **SQL** and **Excel Pivot Tables** for data analysis  
- **Power BI** and **Excel charts** for data visualization  

**Python** and **Excel** were intentionally used in parallel to compare approaches and results.

## Project Structure  
- Python implementation: [python/analysis.ipynb](python/analysis.ipynb)  

## [Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce?select=olist_customers_dataset.csv)
The dataset consists of multiple related tables:
- Customers
- Geolocation
- Order Items
- Order Payments
- Order Reviews
- Orders
- Products
- Products Category Names Translations
- Sellers

## Asked Questions:
- Which product categories generate the highest revenue?
- Which locations have the highest sales?
- What is the average delivery time?
- Are there delays in delivery?

# ETL Process

## Extract 
Data was loaded from multiple CSV files using Python (pandas) and Excel.

## Transform
### Data Integration

The following joins were performed:

    orders LEFT JOIN order_items ON order_id

    orders LEFT JOIN reviews ON order_id

    orders LEFT JOIN customers ON customer_id

    orders LEFT JOIN sellers ON seller_id
  
The goal was to create a unified dataset combining order, product, customer, seller, and review information.

<img width="610" height="500" alt="merge" src="https://github.com/user-attachments/assets/b503510c-83b5-4040-981c-f64fabc64090" />


### Data Aggregation

Due to the join with order_items, each order appeared multiple times (one row per product).

To resolve this, data was aggregated at the order level:

- sum of product values (order_value)
- sum of shipping costs (freight_value)
- count of items per order

This resulted in a second dataset where each row represents a single order.

### Delivery Delays

- Same state: ~0.34 days

Additionally, customer satisfaction (review_score) is slightly higher for same-state deliveries, suggesting a relationship between delivery performance and customer experience.<br><br>


### Customer Satisfaction

<img width="687" height="420" alt="chart_locationToReview" src="https://github.com/user-attachments/assets/80bf1f24-f85d-4047-9546-e1edd48329cb" />

Customer satisfaction is slightly higher when delivery occurs within the same state:

- Same state: ~4.20
- Different state: ~4.02

This suggests that faster and more reliable delivery has a positive impact on customer reviews.

## Conclusion

The analysis shows that delivery performance is strongly influenced by geographical factors.

- Cross-state deliveries take significantly longer  
- Delays are higher for long-distance shipments  
- Faster deliveries are associated with higher customer satisfaction  

These findings highlight the importance of logistics optimization in improving both efficiency and customer experience.
